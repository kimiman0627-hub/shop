# 쇼핑몰 프로젝트 — 문서 홈

이 폴더(`shop/docs`)를 옵시디언 볼트로 열면 이 노트가 시작점이다.
**문서를 여기로 복사해 오지 않았다.** 아래 링크는 전부 실제 문서를 가리킨다 —
사본을 만들면 원본과 어긋나고, 어느 쪽이 맞는지 아무도 모르게 된다.

> [!note] 볼트 범위
> 볼트는 `docs/` 다. `CLAUDE.md` 와 `README.md` 는 저장소 루트라 볼트 밖에 있다
> (루트를 볼트로 잡으면 `vendor`·`node_modules` 의 마크다운 407개가 딸려 들어온다).
> 두 파일은 에디터에서 직접 열면 된다.

## 이 볼트를 쓸 때

- **문서를 고치면 원본이 바뀐다.** 옵시디언에서 편집한 내용이 그대로 저장소에 들어간다.
- 스키마를 바꾸면 [[tables]] 도 같이 고친다. 대조 스크립트는 [[tables#부록: 스키마 다시 뽑기]] 에 있다.
- 새 함정을 밟으면 [[worklog]] 의 `밟으면 아픈 곳` 에 번호를 이어 붙이고, 이 노트의 목록에도 한 줄 추가한다.
- `.obsidian/` 은 개인 설정이라 저장소에 넣지 않는다(`.gitignore`).
