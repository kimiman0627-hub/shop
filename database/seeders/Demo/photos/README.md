# 데모 상품 사진

`shop:demo` 가 상품·상세 이미지로 쓰는 실사 사진 40장.

## 출처와 라이선스

전부 **[Unsplash](https://unsplash.com)** 의 무료 라이선스 사진이다.
[Unsplash License](https://unsplash.com/license) 는 상업·비상업 사용을 모두 허용하고
출처 표기를 요구하지 않는다 — 그래도 아래에 촬영자를 남겨둔다.

**유료(Unsplash+) 사진은 받지 않았다.** 내려받는 스크립트가 `plus.unsplash.com` 을
걸러내고 `images.unsplash.com` 만 쓴다.

## 왜 저장소에 넣어두나

**시드할 때 인터넷을 타지 않기 위해서다.** 시딩 시점에 내려받으면 네트워크가 없거나
원본 서비스가 바뀔 때 `shop:demo` 가 실패한다. 800×800 JPEG(품질 72)로 줄여
전체 3MB 정도다.

파일이 없으면 `DemoPhotoLibrary` 가 예전처럼 GD 로 그려서 채운다 — 사진을 지워도
시딩은 끝까지 돈다.

## 파일 이름 규칙

- 상품 갤러리: `{상품코드}-{n}.jpg` — 예) `tee-01-0.jpg`, `tee-01-1.jpg`
- 상세 이미지: `detail-{n}.jpg` — 후기 시더가 상품 4개에 3장씩 붙인다

상품을 추가하고 사진을 넣으려면 같은 규칙으로 파일을 두면 된다.
